# samples/

Songs, lyrics and sheets for trying hone-music-video on real material. Everything in this folder except
this file is git-ignored: songs and generated media are never committed.

Suggested layout:

```text
samples/<song-name>/
  song.mp3          the audio (WAV, FLAC, MP3, M4A or OGG)
  lyrics.txt        optional: one line per sung line, blank lines between sections
  story.md          optional: notes on the story, setting and characters
  sheets/           optional: reference sheets you already have, named after the character
```
